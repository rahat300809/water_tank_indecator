🧠 Filter & Control Pipeline

• Sampling: 0.5s intervals using HC-SR04 ultrasonic pulses.
• Spike Suppression: Cascaded 2× Low-Pass Filters (α₁ = 0.35, α₂ = 0.25).
• Statistical Engine: 5s window with Median + MAD (Median Absolute Deviation) robust mean.
• Dual Hysteresis: Low threshold (≤ ON%) triggers 20s confirmation; High threshold (≥ OFF%) triggers 10s confirmation.
• Telemetry: Realtime MQTT publishing over devices/ESP32_WATER_01/telemetry.
• Remote Control: Bi-directional MQTT commands via devices/ESP32_WATER_01/command.
